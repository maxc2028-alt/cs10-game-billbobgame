# Alone

**Group Members:** Ethan and Max

## Description

A 2D serious game for teenagers in which players clean up trash in abandoned buildings under a time limit, earn money, upgrade spaces, and make friends. The timed quest mechanic creates urgency and mild stress but also satisfaction, showing how shared efforts to improve neglected spaces can reduce hidden loneliness and build community. The game uses a neighborhood view with clickable trash, timers, progress and money counters, a friendship meter, and clear visual, audio, and text feedback such as “Quest Complete” and “New Friend Joined.”
